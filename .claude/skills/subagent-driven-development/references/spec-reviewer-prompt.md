# 仕様準拠レビュアープロンプトテンプレート

仕様準拠レビューサブエージェントをディスパッチする際にこのテンプレートを使用します。

**目的:** 実装者が要求された通りに構築したか検証する（過不足なく）

```
Task ツール (general-purpose):
  description: "タスク N の仕様準拠をレビュー"
  prompt: |
    あなたは実装が仕様に合致しているかをレビューしています。

    ## 要求された内容

    [タスク要件のテキスト全文]

    ## 実装者が構築したと主張する内容

    [実装者のレポートから]

    ## 重要: レポートを信用しないこと

    実装者は疑わしいほど早く完了しました。レポートは不完全、
    不正確、または楽観的である可能性があります。すべてを独自に検証する必要があります。

    **してはいけないこと:**
    - 実装内容についての実装者の言葉を鵜呑みにする
    - 完全性に関する主張を信用する
    - 要件に対する実装者の解釈を受け入れる

    **すべきこと:**
    - 実際に書かれたコードを読む
    - 実際の実装と要件を一行ずつ比較する
    - 実装したと主張しているが実際には欠落している部分を確認する
    - 言及されていない追加機能を探す

    ## あなたの仕事

    実装コードを読んで以下を検証:

    **欠落した要件:**
    - 要求されたすべてを実装したか？
    - スキップまたは漏らした要件はないか？
    - 動作すると主張しているが実際には実装していないものはないか？

    **余分/不要な作業:**
    - 要求されていないものを構築していないか？
    - 過剰設計や不要な機能の追加はないか？
    - 仕様にない「あれば嬉しい」を追加していないか？

    **誤解:**
    - 要件を意図と異なる形で解釈していないか？
    - 間違った問題を解決していないか？
    - 正しい機能を実装したが方法が間違っていないか？

    **レポートを信用するのではなく、コードを読んで検証すること。**

    報告:
    - 仕様準拠（コード検査後にすべてが一致する場合）
    - 問題あり: [欠落または余分な部分を、ファイル:行の参照とともに具体的にリスト]
```
